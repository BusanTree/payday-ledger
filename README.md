# 월급날 가계부

월급날(기본 25일)을 기준으로 수입·지출을 관리하는 웹 가계부입니다. 빌드 도구 없이 `index.html` 한 파일로 동작하며, GitHub Pages로 그대로 배포됩니다.

- **주기 계산**: 매월 25일(설정 가능) ~ 다음 달 그 전날. 월급날이 주말·공휴일이면 직전 평일로 당겨지고, 관리 기간도 그만큼 짧아집니다. 공휴일은 법정·대체공휴일 기준으로 2025~2035년이 코드에 내장되어 오프라인에서도 계산됩니다.
- **데이터 저장**: 입력한 내역은 서버로 전송되지 않습니다. 브라우저 `localStorage`에만 남고, JSON 백업/복원으로 옮길 수 있습니다.
- **설치**: Android Chrome에서 접속 후 메뉴 → "홈 화면에 추가"를 누르면 앱처럼 열립니다(서비스 워커로 오프라인 동작).

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 앱 본체 (HTML·CSS·JS 단일 파일, 외부 의존성 없음) |
| `manifest.webmanifest` | 홈 화면 추가용 매니페스트 |
| `sw.js` | 오프라인 캐시(서비스 워커) |
| `icons/` | 앱 아이콘 (192/512 PNG, maskable, SVG) |

## 로컬에서 열기

`index.html`을 브라우저로 바로 열어도 동작합니다(서비스 워커는 https 또는 localhost에서만 등록).

## 배포

GitHub Pages — `main` 브랜치 루트를 그대로 게시합니다.
