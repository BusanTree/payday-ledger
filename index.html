–

설정

이 브라우저에서는 자동 저장(localStorage)이 막혀 있어요. 창을 닫으면 입력한 내역이 사라질 수 있으니 설정에서 JSON 백업을 받아두세요.
기간 관리

월급날 기준으로 설정하면 매월 지정한 날부터 다음 달 그 전날까지 자동으로 계산돼요. 월급날이 주말·공휴일이면 그 전 평일로 당겨지고(예: 12.25 성탄절 → 12.24), 그만큼 기간도 짧아져요. 공휴일은 법정·대체공휴일 기준으로 2025~2035년까지 저장돼 있어 인터넷 없이도 계산해요.

카테고리 관리
지출
수입

카테고리를 지우면 그 카테고리로 기록된 내역은 '기타/이월·기타'로 옮겨져요. 왼쪽 아이콘을 눌러 이모지를 고르고 이름을 적으면 바로 추가돼요. 입력 화면의 '＋ 추가'로도 그 자리에서 만들 수 있어요.

데이터
사용 방법
  1. 기간을 월급날 기준(예: 매월 25일)으로 정하면 25일~다음 달 24일이 기본이에요. 25일이 주말·공휴일이면 그 전 평일로 당겨져요(12.25 성탄절 → 12.24 지급이면 12.23까지 관리).
  2. 오른쪽 아래 + 버튼으로 수입·지출을 기록해요. 기간 밖 날짜는 저장되지 않아요.
  3. 카테고리를 새로 만들려면 입력 화면 카테고리 줄 끝의 '＋ 추가'를 누르거나, 설정 → 카테고리 관리에서 아이콘(이모지)까지 골라 추가하면 돼요.
  4. 폰에서는 이 파일을 다운로드 폴더에 두고 Chrome으로 열면 돼요.
  5. Chrome 오른쪽 위 ⋮ 메뉴에 '홈 화면에 추가'가 보이면 눌러 두세요. 없으면 북마크로 저장해 두면 돼요.
  6. 데이터는 이 브라우저에만 있어요. 폰을 바꾸기 전에 JSON 백업을 받아두세요.
